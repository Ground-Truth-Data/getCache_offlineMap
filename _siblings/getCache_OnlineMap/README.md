# getCache_OnlineMap

The online Mapbox map child of Get Cache, served by `ReTreever/` (or a rapper
install) through `$parent/siblings/getCache_OnlineMap`. Its one doc is
[`docs/SAFE_MAP.md`](./docs/SAFE_MAP.md) — every camera mutation goes through
`lib/safeMap.ts`. The map index lives in the parent at
`ReTreever/src/lib/mobile/docs/mapDocs.md`.
